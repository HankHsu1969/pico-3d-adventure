# 皮可 3D 大冒險（Pico's 3D Adventure）

受《超級瑪利歐 3D 世界》啟發的瀏覽器 3D 平台跳躍遊戲。原創主角「皮可」要穿越五個世界，打敗咕嚕大王，奪回彩虹大星星。

## 怎麼玩

**電腦**：雙擊 `start.bat`（需要安裝 Python），瀏覽器會自動打開 http://localhost:8080 。

**手機（橫放）**：電腦先執行 `start.bat`，手機連同一個 Wi-Fi，打開 `http://電腦IP:8080`（IP 可用 `ipconfig` 查詢）。第一次可能要允許 Windows 防火牆。

> 必須透過伺服器開啟，直接雙擊 index.html 會因瀏覽器安全限制無法載入模組。

## 操作

| 動作 | 鍵盤 | 手機 | 手把 |
|---|---|---|---|
| 移動 | WASD / 方向鍵 | 左半邊虛擬搖桿 | 左搖桿 |
| 跳躍（按住跳更高） | 空白鍵 / K | 「跳」 | A |
| 奔跑 | Shift / J | 「衝」或搖桿推到底 | X / B |
| 旋轉鏡頭 | Q / E | ⟲ ⟳ | LB / RB |
| 暫停 | Esc / P | 右上角按鈕 | Start |

## 五個關卡

1. **晴空草原**：教學關，★方塊、彈簧、移動平台
2. **夕陽沙漠**：沙岩石柱、會掉落的地板、刺刺球
3. **冰雪山峰**：很滑的冰面、攀爬、上下移動平台
4. **雲端王國**：雲朵、彩虹橋、繞圈平台、嗡嗡蜂
5. **熔岩城堡**：火焰棒、壓壓石、岩漿，最後是魔王咕嚕大王

每關藏有 3 顆綠色星星寶石（共 15 顆），進度會自動存在瀏覽器裡。

## 技術

- Three.js（已放在 `lib/`，不需要網路）＋ 原生 ES Modules，不需要建置流程
- 角色、敵人、道具、平台都是程式產生的 3D 模型
- 背景、標題、結局、角色插圖由 Higgsfield（GPT Image 2）生成，放在 `assets/`（原始 PNG 在 `assets/source/`）
- 音樂與音效用 WebAudio 即時合成，全部是原創旋律

## 檔案

- `js/main.js`：畫面切換、HUD、存檔、主迴圈
- `js/game.js`：物理、玩家、敵人、魔王、相機
- `js/levels.js`：五個關卡的配置
- `js/world.js`：關卡建構器、主題、平台
- `js/models.js`：3D 模型與貼圖
- `js/audio.js`：音樂與音效
- `js/input.js`：鍵盤、觸控、手把
- 除錯：網址加上 `?level=3` 可以直接進入第 3 關
